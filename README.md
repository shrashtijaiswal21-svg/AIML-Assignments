
# AIML Assignments

This repository contains 10 Artificial Intelligence and
Machine Learning assignments implemented using Python.

## Assignments

1. Association and Correlation Analysis
2. K-Means Clustering
3. Principal Component Analysis (PCA)
4. Naive Bayes Classification
5. K-Nearest Neighbors (KNN) Classification
6. Linear Regression
7. Support Vector Regression (SVR)
8. Regularization using Ridge and Lasso
9. Object Detection from CCTV Footage using YOLO
10. Fake News Detection using Text and Image Features

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- OpenCV
- Ultralytics YOLO
- Pillow

## Setup

Install the required libraries:

```bash
python3 -m pip install numpy pandas matplotlib scikit-learn opencv-python ultralytics pillow
```

Run an assignment using:

```bash
python3 association.py
```

Replace `association.py` with the filename
of the assignment you want to execute.

## Notes

- CCTV object detection requires a video file and YOLO model weights.
- Fake news detection uses a small synthetic dataset for demonstration.
- Model accuracy on synthetic data does not indicate real-world performance.
